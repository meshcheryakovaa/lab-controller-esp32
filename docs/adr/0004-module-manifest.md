# ADR-0004. Self-describing модули: манифест как единственный источник истины

**Статус:** принято (Milestone 0)

## Context

Главный критерий качества проекта (§63): добавление поддерживаемого датчика не должно
требовать изменений во frontend. Наивный путь — писать по странице настроек на каждый
тип датчика — приводит к тому, что после десятого сенсора UI перестаёт развиваться.

## Decision

Каждый тип модуля объявляет `static constexpr ModuleManifest` во flash:
id, категория, требуемая шина, `ParamSpec[]` (тип поля, диапазон, шаг, значение по
умолчанию, варианты, условие видимости, флаг advanced, требуемое назначение пина),
`ChannelSpec[]` (id, имя, единица, физическая величина, направление, диапазон,
точность), лимит экземпляров, границы частоты опроса, `schemaVersion`.

Манифест используется:

* `GET /api/v1/modules` → frontend строит форму целиком;
* `DeviceManager::validate()` → проверка конфигурации до создания драйвера;
* `ResourceManager` → какие пины захватывать и с каким `PinUse`;
* `DeviceManager` → создание каналов по `ChannelSpec` (драйвер каналы не создаёт).

## Alternatives

* **Страница настроек на каждый датчик.** Линейный рост работы в UI, расхождение
  логики валидации между браузером и прошивкой.
* **JSON-схемы в LittleFS.** Гибче, но занимает место, требует синхронизации с кодом
  и допускает состояние, когда схема есть, а драйвера нет.
* **Генерация манифестов из кода на этапе сборки.** Дополнительная машинерия ради
  экономии нескольких строк на модуль.

## Consequences

**Плюсы.** Новый датчик = драйвер + манифест + две строки регистрации; изменений во
frontend ноль. Валидация одна и та же в браузере и в прошивке. Форма всегда
соответствует тому, что реально читает драйвер.

**Минусы.** Манифест занимает flash (~200–400 байт на модуль). Выразительность
`ParamSpec` ограничена: сложные зависимости между полями поддерживаются только
простым `visible_if`. Если конкретному модулю понадобится нестандартный элемент
интерфейса, придётся расширять `ParamSpec` и `SchemaForm`, а не делать исключение —
и это осознанная жёсткость.

**Правило контроля.** Появление `if (module.id === '…')` во frontend считается
дефектом архитектуры и чинится расширением манифеста.
