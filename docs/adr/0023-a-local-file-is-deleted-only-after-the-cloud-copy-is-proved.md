# ADR-0023 — Локальный файл удаляется только после доказанной копии в облаке

**Статус:** принято, Milestone 17
**Контекст:** `services/CloudManager`, `storage/CloudUploadQueue`, `platform/esp32/Yandex*`

## Проблема

M15 сделал флеш контроллера буфером передачи: сегмент удаляется после того, как
браузер подтвердил приём. M17 убирает браузер из этой цепочки — контроллер сам
отправляет сегменты на Яндекс Диск, и делает это с закрытой вкладкой, сутками.

Соблазнительная реализация — «загрузили, получили 200, удалили». Она неверна, и
неверна тихо.

Соединение может оборваться **после** того, как сервер сохранил файл, но **до**
того, как ответ дошёл. С точки зрения контроллера это неотличимо от обрыва
посреди передачи. Одно из двух решений создаст дубликат, другое — потеряет
данные, и оба выглядят как успех.

## Решение

> Локальный файл удаляется только после того, как **удалённый объект прочитан
> обратно** по окончательному пути и совпал по размеру и MD5.

Не «после ответа 200». Ответ — это утверждение сервера о прошлом; `stat()` —
это факт о настоящем.

### Порядок, который делает повтор безопасным

1. **Сначала спросить, что уже есть.** Перед первой же отправкой, а не только
   перед повтором. Если по окончательному пути лежит файл с нашими размером и
   MD5 — работа сделана, отправлять нечего.
2. **Загружать во временное имя** `<файл>.uploading`. Частичная передача
   никогда не занимает окончательный путь, поэтому «не отправляли» отличимо от
   «отправили и переименовали».
3. **Проверить временный объект**, потом переименовать, потом **проверить
   окончательный**. Только после этого — подтверждение в очереди и удаление.
4. **`overwrite=true` запрещён** для файлов журнала. Совпадение имён должно
   останавливаться и спрашивать, а не уничтожать то, что там было.

Если питание пропало между записью подтверждения и удалением файла, при
следующем запуске проверка повторяется по удалённым метаданным и удаление
безопасно завершается.

### Что означает «другой файл по этому пути»

`REMOTE_CONFLICT` и остановка. Не перезапись, не автоматическое переименование.
Файл с тем же именем и другим содержимым — это либо чужой контроллер, либо
прошлый запуск, и решать, что с этим делать, должен человек.

Исключение — **наш** временный `.uploading`, который не совпадает: он бесполезен
по определению и удаляется, иначе неудачная попытка блокировала бы путь навсегда.

## Что ещё следует из правила

* **Очередь не удаляет ничего.** Она хранит метаданные; сами измерения лежат в
  `/data/logs`. Повреждённая очередь останавливает выгрузку и **не** трогает ни
  одного CSV — это причина, по которой она не перезаписывается при ошибке
  разбора: файл очереди может быть единственной записью о том, какие данные есть
  только здесь.
* **Отсутствие сети не считается попыткой.** Неделя без роутера не должна
  исчерпать расписание повторов и загнать все сегменты в `PERMANENT_ERROR`.
* **Пропавший локальный файл — ошибка, а не подтверждение.** Записать это как
  «выгружено» значило бы солгать о том, где данные.
* **Ошибка облака никогда не останавливает эксперимент.** Датчики, управление и
  локальная запись продолжаются; выгрузка — это способ забрать данные, а не
  условие их получения.

## Секреты

Токены и Client Secret не возвращаются никогда — и это обеспечено не фильтрацией,
а тем, что в `ICloudAccount` **нет метода**, который мог бы их вернуть. API
сообщает `clientSecretSet: true`, что отвечает на единственный нужный вопрос.

Токен уходит только на `cloud-api.yandex.net`. Сама загрузка — это PUT на
одноразовый URL на другом хосте, и он идёт **без** заголовка авторизации: URL
сам по себе является правом на запись, а токен там был бы подарком тому, кто
ответил. Этот URL — единственное место в фиче, где адрес назначения выбирает
удалённый ответ, поэтому он проверяется по списку доменов до отправки байтов.

## Известное ограничение

Обычная ESP32 без Flash Encryption и NVS Encryption **не является защищённым
хранилищем** при физическом доступе к плате. Токен можно прочитать из флеша.

Это зафиксировано, а не спрятано: интерфейс показывает предупреждение, а
рекомендация — выдавать OAuth-приложению права **только на Диск**, чтобы худший
случай был «чужие лабораторные CSV», а не «аккаунт».

## Цена

Каждый сегмент стоит трёх дополнительных запросов метаданных (до, после
загрузки, после переименования) и одного переименования. На 100 КиБ это
несколько процентов трафика.

Альтернатива — доверять коду ответа — экономит их и взамен делает потерю данных
неотличимой от успеха. Для прибора, который стирает измерения по результату
этой проверки, обмен очевиден.
